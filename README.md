# Dashboard de Vendas – Power BI

## 📌 Objetivo
Este dashboard tem como objetivo analisar o desempenho de vendas,
permitindo ao gestor acompanhar faturamento, quantidade de vendas,
produtos mais vendidos e desempenho por período.

## 📊 Principais KPIs
- Faturamento total
- Quantidade de vendas
- Ticket médio
- Produtos mais vendidos
- Evolução de vendas ao longo do tempo

## 🛠 Ferramentas utilizadas
- Power BI
- Power Query
- DAX (medidas básicas)

## 👥 Público-alvo
Gestores comerciais e donos de pequenos negócios.
